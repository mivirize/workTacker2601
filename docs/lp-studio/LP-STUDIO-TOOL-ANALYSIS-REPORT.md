**更新日:** 2026-02-06

**運営:** 株式会社HN Lab

## エグゼクティブサマリー

LP STUDIOは月額定額制のLP制作サービスであり、3つの内製ツール（LP Generator, LP Editor, LP Site Cloner）がサービス提供の技術基盤を構成している。本レポートでは、各ツールのLP STUDIOサービスへの貢献度を定量評価し、サービス提供に不足している機能のギャップ分析を行った。

### 主要な発見

- **総合自動化率: 約68%** — LP制作の全10工程のうち、約7割をツールでカバー
- **LP Generatorが最大の差別化要因** — 原価を70%削減し、月額22万円の価格設定を成立させる核心技術
- **致命的ギャップが4つ存在** — デプロイ、GA4タグ、フォームバックエンド、ツール間統合
- **ツール間連携の不在** が最大のボトルネック — 個々のツールは十分だがフローが分断

## 1. LP STUDIOサービス概要

### 1.1 料金プラン

| プラン | 料金 | ポジショニング |
|--------|------|---------------|
| **ショットプラン** | 〜¥100,000/本（税込） | 単発利用・お試し向け |
| **ベースプラン** | **¥220,000/月**（税込・月額定額） | メインプラン・量産運用向け |
| **完全運用プラン** | お見積もり | 制作+改善運用の包括プラン |

### 1.2 ベースプランの提供内容

**含まれるもの:**
- 月額定額でのLP制作（デザイン・実装）
- 構成整理・コピー整形
- フォーム設置
- 計測タグ設置（GA4等）
- 公開サポート
- 軽微な修正は無制限

**含まれないもの:**
- 広告運用代行
- 撮影・イラスト制作
- システム開発
- 複雑な会員機能
- ドメイン・サーバー費用

### 1.3 サービスの差別化ポイント

- **最短3営業日で初稿** — 業界平均（2-4週間）の数倍のスピード
- **修正無制限** — 通常2-3回が上限の会社が多い
- **計測タグ・フォーム込み** — 別途見積もりの会社が多い要素を含む
- **著作権帰属** — 完済後にクライアントに帰属（好条件）

## 3. 各ツール詳細分析

### 3.1 LP Generator

#### 概要
Next.js 15ベースのモノレポWebアプリケーション。Claude AIを活用してヒアリング情報からLPを自動生成する。

#### 主要機能

| 機能 | 説明 | 完成度 |
|------|------|--------|
| HearingWizard | 5ステップのヒアリングフォーム（顧客情報→商品情報→ターゲット→デザイン→確認） | ✅ 完成 |
| AI生成パイプライン | Claude API → レスポンス解析 → ブロック検証 → フォールバック | ✅ 完成 |
| テンプレートティア | Simple(3ブロック) / Rich(6) / Premier(11) | ✅ 完成 |
| 11ブロックタイプ | Hero, Feature, CTA, Benefit, Testimonial, FAQ, Pricing, Form, Gallery, Video, Text | ✅ スキーマ完成 |
| ブロックエディタ | Drag & Drop対応のブロック並べ替え | ✅ UI完成 |
| ライブプレビュー | リアルタイムLP表示 | ✅ 完成 |
| SEO設定 | タイトル、ディスクリプション、OGP | ✅ スキーマ完成 |
| 公開スケジュール | 公開/非公開の日時指定 | ✅ スキーマ完成 |
| Sanity CMS接続 | 実データベース連携 | ❌ Mock DB |
| NextAuth認証 | ユーザー認証 | ❌ 未実装 |
| 画像アップロード | 画像管理・処理 | ❌ 未実装 |

#### AI生成フロー

```
HearingWizard (5ステップ)
    │
    ▼
buildLpGenerationPrompt(input)  ← ヒアリング情報をプロンプトに変換
    │
    ▼
generateWithClaude({              ← Claude Sonnet API呼び出し
  model: 'claude-sonnet-4-20250514',
  maxTokens: 4000,
  temperature: 0.7
})
    │
    ▼
parseAIResponse(responseText)     ← JSON抽出・構造解析
    │
    ▼
validateAndSanitizeBlocks()       ← Zod検証 + UUID生成 + デフォルト値
    │
    ▼
GenerationResult {
  blocks: LpBlock[],              ← 検証済みブロック配列
  source: 'ai' | 'fallback',
  analysis: { industry, persona, tone },
  designRecommendations: { layout, colors, icons }
}
```

#### LP STUDIOへの貢献

**サービスの「最短3営業日初稿」を技術的に実現可能にする核心技術。**

- 構成設計 + コピーライティングの自動化で、通常2-4週間の工程を数時間に短縮
- テンプレートティアリングにより、「内容によりお見積もり」のバリエーションに対応
- フォールバック機構でAI障害時もサービス継続可能

| リピートブロック | 動的コンテンツの追加・削除・編集 | ✅ 完成 |

| バリデーション | リンク・画像・テキスト・HTML構造チェック | ✅ 完成 |
| デザインスコア | アニメーション・レイアウト・アクセシビリティ評価 (0-100) | ✅ 完成 |

### 3.3 LP Site Cloner

#### 概要
Playwright駆動のWebスクレイピング＆分析ツール。デザインギャラリーサイトからURLを収集し、各サイトのデザインパターンを自動抽出する。

#### 主要機能

| 機能 | 説明 | 完成度 |
|------|------|--------|
| ギャラリースクレイピング | 5サイト対応（イケサイ, SANKOU!, Web Design Garden等） | ✅ 完成 |
| サイト分析 | CSS/JS/DOM解析によるパターン抽出 | ✅ 完成 |
| バッチ分析 | 単一ブラウザ再利用・リトライ・進捗表示 | ✅ 完成 |
| パターンDB | JSON形式ライブラリ（533パターン） | ✅ 完成 |
| Claude Code統合 | `~/.claude/rules/lp-site-patterns.md`自動更新 | ✅ 完成 |
| LP Generator連携 | 分析結果のGenerator自動フィード | ❌ 未実装 |

#### 抽出パターン種別

| カテゴリ | パターン数 | 内容例 |
|----------|-----------|--------|
| アニメーション | 465 | float, rotate, fade, slide, scale |
| エフェクト | 108 | グラデーション, マスク, フィルター |
| タイポグラフィ | 69 | フォント, サイズ, 行高 |
| カラー | 67 | カラーパレット |
| コンポーネント | 4 | スライダー設定 |
| **合計** | **533** | |

#### 分析実績（2026-02-05時点）

- 収集サイト数: 76（4ギャラリー × 20ページ）
- 分析成功: 63サイト（成功率83%）
- 分析時間: 約52分（平均41秒/サイト）
- 分析済みサイト: 71（累計）

#### LP STUDIOへの貢献

**デザイン品質を業界水準以上に保つための知識基盤。**

- 実サイトの533パターンがClaude Code経由でLP制作時に自動参照
- 競合分析データにより顧客提案の説得力向上
- トレンドに即したデザイン判断の根拠

## 6. ギャップ分析

### 6.1 致命的ギャップ（サービス提供に直結）

#### GAP-1: デプロイ/公開パイプライン 🔴

**LP STUDIOは「公開サポート」をサービスに含んでいるが、自動デプロイ機能がどのツールにも存在しない。**

| 項目 | 現状 | 必要な状態 |
|------|------|-----------|
| 出力形式 | LP EditorからHTMLファイル出力 | ワンクリックでホスティングにデプロイ |
| ホスティング | 手動でサーバーにアップロード | Vercel / Cloudflare Pages / S3+CloudFront |
| ドメイン | 顧客任せ | カスタムドメイン設定支援UI |
| SSL | 手動設定 | 自動SSL証明書 |

**ビジネスインパクト:** 公開まで手動作業が必要 → 「3営業日初稿」の後、公開に追加時間が必要。

**推奨対策:** Vercel API / Cloudflare Pages API と連携したワンクリックデプロイ機能をLP Editorに追加。

---

#### GAP-2: 計測タグ設置（GA4等） 🔴

**LP STUDIOは「計測タグ設置（GA4等）」を明記しているが、自動設置機能がない。**

| 項目 | 現状 | 必要な状態 |
|------|------|-----------|

**ビジネスインパクト:** サービス内容として明記しているため、未対応は契約違反リスク。

**推奨対策:** LP Editorに「計測タグ」設定タブを追加。タグIDを入力するだけで`<head>`に自動挿入。

#### GAP-3: フォーム送信バックエンド 🔴

## 9. 結論と提言

### 9.1 LP Generatorの位置づけ

LP Generatorは LP STUDIOの**心臓部**であり、サービスの最大の差別化要因である「最短3営業日初稿」と「月額22万円での量産」を技術的に実現する核心技術である。

**数値的裏付け:**
- LP制作原価を**74%削減**（255,000円 → 65,000円）
- 構成設計+コピーライティングを**数分**で完了（通常2-4週間）
- 月2本制作で**利益率41%**を確保

### 9.2 現在の最大ボトルネック

3つのツールが**分断されている**こと。

個々のツールは十分な機能を持っているが、LP STUDIOのサービスフローとして一気通貫で繋がっていない。この分断により:
- ツール間の手動変換作業が発生（推定1-2時間/案件）
- ヒューマンエラーのリスク
- スケーラビリティの制限

### 9.3 即座に着手すべき3項目

| 優先順 | 項目 | 理由 |
|--------|------|------|
| **1** | LP GeneratorのSanity CMS接続 | Mock DBのままではサービス提供不可 |
| **2** | GA4タグ設置機能 | サービス内容として明記済み・契約上必須 |
| **3** | Generator → Editor の連携 | ツール統合の最初の一歩・最大のインパクト |

### 9.4 中期的な戦略提言

1. **月間制作本数の上限設定を検討** — 月3本以上は利益率が急落するため、ベースプランに「月2本まで」等の制限を設けるか、超過分は追加料金とすることを推奨

2. **完全運用プランの価格帯** — A/Bテスト+ダッシュボード+改善提案を含む場合、月額40-60万円が妥当。Phase 3完了後に本格提供開始

3. **LP Site Clonerの戦略的活用** — 現在は「参考資料」止まりだが、顧客向けの「競合分析レポート」として有料提供することも可能（付加価値の創出）

4. **LP Editorの顧客提供** — EXE同梱エクスポート機能を活用し、完全運用プランの顧客に「セルフ編集ツール」として提供することで解約率低減

**実装ファイル: `src/renderer/services/html-service.ts`**
```typescript
export function injectTrackingTags(html: string, analytics: AnalyticsConfig): string {
  const $ = cheerio.load(html);
  const head = $('head');

  // GA4
  if (analytics.ga4?.enabled && analytics.ga4.measurementId) {
    const ga4Script = `
      <script async src="https://www.googletagmanager.com/gtag/js?id=${analytics.ga4.measurementId}"></script>
      <script>
        window.dataLayer = window.dataLayer || [];
        function gtag(){dataLayer.push(arguments);}
        gtag('js', new Date());
        gtag('config', '${analytics.ga4.measurementId}');
      </script>
    `;
    head.append(ga4Script);
  }

  // Facebook Pixel
  if (analytics.fbPixel?.enabled && analytics.fbPixel.pixelId) {
    const fbScript = `
      <script>
        !function(f,b,e,v,n,t,s){...}(window, document,'script',
        'https://connect.facebook.net/en_US/fbevents.js');
        fbq('init', '${analytics.fbPixel.pixelId}');
        fbq('track', 'PageView');
      </script>
    `;
    head.append(fbScript);
  }

  return $.html();
}
```

export function configureFormActions(html: string, forms: FormConfig[]): string {
  const $ = cheerio.load(html);

  forms.forEach(form => {
    const formEl = $(`form[data-form-id="${form.id}"], form#${form.id}`);
    if (formEl.length) {
      formEl.attr('action', form.endpoint);
      formEl.attr('method', 'POST');

      // Formspree用の隠しフィールド
      if (form.provider === 'formspree') {
        formEl.append(`<input type="hidden" name="_next" value="${form.successRedirect}">`);
        formEl.append('<input type="hidden" name="_captcha" value="true">');
      }
    }
  });

  return $.html();
}
