# LP制作ヒアリングテンプレート

> **使い方**: このテンプレートは対話形式で使用します。各質問には「深掘り質問」を用意しており、
> 表面的な回答から潜在的なニーズを引き出すことを目的としています。

---

## 事前準備チェックリスト

ヒアリング前に以下を確認・準備してください：

- [ ] クライアントのWebサイト/SNSを事前調査
- [ ] 業界の競合サイトを3-5社リサーチ
- [ ] 類似業界のLP事例を5-10件収集
- [ ] クライアントの口コミ・レビューを確認
- [ ] 業界のトレンド・課題を把握

## PHASE 1: アイスブレイク（5分）

### 1-1. 導入

```
本日はお時間いただきありがとうございます。
〇〇様のビジネスについて深く理解し、成果の出るLPを作りたいと思っています。
まずは御社のことを教えていただけますか？
```

### 1-2. オープニング質問

| 質問 | 目的 |
|------|------|
| 「このLP制作を検討されたきっかけは何でしたか？」 | 本質的な課題を探る |
| 「理想的な結果が出たら、どんな状態になりますか？」 | ゴールイメージの共有 |

## PHASE 2: ビジネス理解（15分）

### 2-1. 基本情報

| 項目 | 質問例 | 回答欄 |

| 会社名 | - | |

| 業種 | - | |
| 設立年 | - | |
| 従業員数 | - | |
| 所在地 | - | |

### 2-2. サービス理解（重要）

#### メイン質問
```
御社のサービス/商品を、お客様に説明するとき
どのように伝えていますか？
```

#### 深掘り質問
- 「それを聞いたお客様は、どんな反応をされますか？」
- 「競合と比べて、ここだけは負けないという点は？」
- 「逆に、よく誤解されることはありますか？」
- 「お客様から『〇〇があったらいいのに』と言われることは？」

#### 隠れたニーズを探る質問
```
もし制約が一切なかったら、本当はどんなサービスを
提供したいですか？
```

### 2-3. 現状の課題

#### メイン質問
```
今、一番困っていること、解決したいことは何ですか？
```

#### 深掘り質問（5 Whys テクニック）
1. 「それは、なぜ問題だと感じますか？」
2. 「その原因は何だと思いますか？」
3. 「それが解決すると、どう変わりますか？」
4. 「今まで、解決のために試したことはありますか？」
5. 「それがうまくいかなかった理由は？」

#### チェックリスト（該当するものを確認）
- [ ] 集客が足りない
- [ ] 問い合わせはあるが成約しない
- [ ] 単価が低い/値引きされる
- [ ] リピートが少ない
- [ ] 競合に負けている
- [ ] 認知度が低い
- [ ] ブランドイメージが定まらない
- [ ] 既存サイトが古い/機能していない

## PHASE 10: 潜在ニーズの発掘（10分）

> **このフェーズが最も重要です**
> 表面的な要望の奥にある本当のニーズを探ります

### 10-1. 未来志向の質問

```
3年後、御社はどんな会社になっていたいですか？
このLPはその実現にどう貢献しますか？
```

### 10-2. 理想と現実のギャップ

```
「本当はこうしたいけど、今はできていない」
ということはありますか？
```

### 10-3. 恐れ・不安の確認

```
このLP制作で、心配なこと、不安なことはありますか？
過去に嫌な経験をされたことは？
```

### 10-4. 意思決定の背景

```
今回、LP制作を決断された一番の理由は何ですか？
今やらなければならない理由は？
```

### 10-5. 隠れた制約の確認

```
社内で「これは絶対にダメ」と言われていることや、
業界のルールで制限されることはありますか？
```

### 10-6. 関係者の期待

```
このLPに対して、社長/上司/チームメンバーは
どんな期待をされていますか？
```

## 付録：業界別追加質問

### A. 美容・健康系
- 「ビフォーアフターで見せられる事例はありますか？」
- 「効果の個人差について、どう説明されていますか？」
- 「医療広告ガイドラインへの対応は？」

### B. 教育・スクール系
- 「受講生の成果で数字で示せるものは？」
- 「挫折する人の特徴と、その対策は？」
- 「無料体験からの成約率は？」

### C. BtoB系
- 「導入の意思決定に関わる人は何人ですか？」
- 「稟議を通すために必要な情報は？」
- 「競合比較表があると助かりますか？」

### D. EC・物販系
- 「返品率はどのくらいですか？」
- 「リピート率と、リピートの理由は？」
- 「ギフト需要はありますか？」

### E. 不動産・高額商材系
- 「来店/来場の動機で多いものは？」
- 「検討期間はどのくらいですか？」
- 「夫婦/家族での意思決定が多いですか？」

## 付録：深掘り質問テクニック

### 1. 5 Whys（なぜを5回）
表面的な回答から根本原因を探る

### 2. 反対質問
「逆に〇〇でないのはなぜですか？」

### 3. 仮定質問
「もし〇〇だったら、どうしますか？」

### 4. 比較質問
「〇〇と比べて、どう違いますか？」

### 5. 具体化質問
「具体的に、例を挙げていただけますか？」

### 6. スケール質問
「1〜10で表すと、今は何点ですか？」

### 7. 沈黙の活用
回答後3秒待つと、追加情報が出てくることが多い
