Container Queries

Resize to See Effect

コンテナサイズに応じてレイアウトが自動変更

Responsive Card

このカードはコンテナ幅に応じて縦/横レイアウトが切り替わります。

Container Queries
Current width: 400px

Implementation

CSS

.card-container {
  container-type: inline-size;
  container-name: card;
}

/* 小さいコンテナ: 縦並び */
.cq-card {
  display: flex;
  flex-direction: column;
}

/* 300px以上: 横並び */
@container card (min-width: 300px) {
  .cq-card {
    flex-direction: row;
  }
  .cq-card__title {
    font-size: 1.25rem;
  }
}

/* 500px以上: さらに拡張 */
@container card (min-width: 500px) {
  .cq-card__image {
    flex: 0 0 200px;
  }
}
